Pemodelan Regresi Linear Berganda

Perhitungan Manual (Matriks)

Perhitungan nilai \(\hat{\beta}\) secara matriks dapat dilakukan dengan rumus berikut.

\[\hat{\beta} = (X'X)^{-1} X'y\] ### Membentuk Matriks X dan Y

n <- nrow(dt)

x0 <- rep(1,n)

X <- cbind(
  x0,
  dt$`Indeks Pembangunan Manusia`,
  dt$`Persentase Penduduk Miskin`,
  dt$`Persentase RT Terhadap Sanitasi Layak`,
  dt$`Persentase RT terhadap Sumber Air Minum Layak`,
  dt$`Persentase Memiliki Jaminan Kesehatan`,
  dt$`Kepadatan Penduduk`
)

X <- as.matrix(X)

Y <- dt$`Jumlah Penyakit DBD`

Menghitung Dugaan Parameter

beta_duga <- solve(t(X)%*%X)%*%t(X)%*%Y

Hasil tersebut menjelaskan bahwa persamaan yang terbentuk adalah \[\hat{JPD}=1488.57-14.97IPM-15.65PM+0.38RTSL+1.91RTAML−0,66JK-0,02KP\] Selang kepercayaan dan pengujian signifikansi setiap parameter dapat dilakukan dengan menghitung keragaman tiap dugaan parameter. Secara umum, nilai ragam dugaan parameter \(\hat{\beta}_j\) dapat dihitung melalui rumus berikut.

\[Var(\hat{\beta}_j) = \hat{\sigma}^2 C_{jj}\] Dengan matriks \(C\) adalah matriks \((X'X)^{-1}\)

Unsur diagonal dari matriks \(C\) dapat digunakan untuk menghitung nilai galat baku dari setiap dugaan parameter. Galat baku ini dapat digunakan untuk menghitung selang kepercayaan dari dugaan yang dihasilkan.

\[SE(\hat{\beta}_j) = \sqrt{Var(\hat{\beta}_j)} = \sqrt{\sigma^2 C_{jj}} = \hat{\sigma}\sqrt{c_{ii}}\] ### Persamaan Regresi

Kriteria umum:

  • VIF < 5 : Tidak ada multikolinearitas serius
  • 5 ≤ VIF < 10 : Multikolinearitas sedang
  • VIF ≥ 10 : Multikolinearitas tinggi

Hasil uji ini menunjukkan peubah IPM memiliki nilai VIF yang cenderung tinggi (>5). Uji Hipotesis Kesamaan Parameter Regresi

Hipotesis yang diuji adalah

\[H_0: β1=β2=β3=β4=β5=β6\] \[H_1: β1≠β2≠β3≠β4≠β5≠β6\]
